# A 股多因子量化分析工作台

基于 DeepSeek v4 Pro 大模型的 A 股多因子量化分析平台，集数据采集、AI 智能分析、时序价格预测、多因子打分、事件研究与等权组合模拟于一体。系统通过免费/公开数据接口获取行情数据，借助 Kronos 时序模型生成价格预测，并在此基础上构建等权组合模拟框架，输出综合评分、夏普比率、最大回撤、相关性热力图等关键指标的可视化报告。

## 核心功能

- **多源数据采集**：接入东方财富（efinance）、腾讯财经、Akshare 等公开接口，支持多源容错与自动切换
- **AI 智能分析**：调用 DeepSeek v4 Pro（经 LiteLLM SDK），输出综合评分、趋势预测、操作建议、风险提示等结构化 JSON
- **时序价格预测**：使用 Kronos 模型对 60 个交易日的收盘价进行预测
- **多因子打分体系**：11 种技术分析策略，按趋势、动量、估值、质量、情绪五个维度加权评分（0-10 分），映射为 Level 1-5 评级
- **等权组合模拟**：以 Kronos 预测数据为输入，计算累计收益、年化收益、夏普比率、最大回撤与胜率
- **事件研究**：对分红公告等事件对股价的短期市场影响进行定量分析

## 技术栈

- Python 3.10
- `efinance`：东方财富数据接口
- `akshare`：公共数据源
- `pandas`：数据处理
- `litellm`：DeepSeek API 调用
- Kronos：时序预测模型

## 快速开始

```bash
# 1. 安装依赖
pip install efinance akshare pandas litellm

# 2. 配置 DeepSeek API 密钥（通过环境变量注入，不写入代码）
export DEEPSEEK_API_KEY="your_api_key"

# 3. 运行主程序
python main.py
```

运行后系统将自动完成数据抓取、AI 分析、价格预测与组合模拟全流程，并生成可视化报告。
